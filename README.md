## 🚀 Features

- Real-time hand tracking using MediaPipe
- Volume control using the distance between fingertips
- Visual volume bar and percentage display
- Frame rate (FPS) counter
- Works with Windows system audio (via Pycaw)

## 🛠️ Tech Stack

- Python 3.x
- OpenCV
- MediaPipe
- NumPy
- Pycaw (for system audio control)
- comtypes (used by Pycaw)
